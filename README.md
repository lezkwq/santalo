# santalo

Crie uma landing page completa, editorial, premium e extremamente bem resolvida para a Santalo Móveis Sob Medida, empresa de Itajaí, Santa Catarina.

Este não é um site genérico de marcenaria e não deve parecer um template de móveis planejados. A Santalo tem história, produção própria, execução real, mais de uma década de atuação e um acervo muito bom de projetos concluídos. Quero que o design transmita isso.

O resultado precisa parecer trabalho de um estúdio de design digital de alto nível aplicado a uma marca brasileira de móveis sob medida.
